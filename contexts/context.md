# 项目工程上下文 (Operational Context)

DeskSticky 是放在 Windows 桌面上的一张便利贴。用户在这里记下待办，窗口可以贴边收起、置顶和开机拉起。数据只留在本机。

## 一、 技术栈与运行环境

- **基础运行环境**: Windows 10/11。开发机 Node.js 20 及以上。运行已打包程序不需要 Node 或 Rust，但目标电脑必须已有 WebView2 Runtime。
- **核心框架**: 界面 React 19.3、TypeScript 5.9、Vite 6、Tailwind 4、Vitest 3。壳层 Tauri 2.12、Rust 2021 edition。窗口与注册表使用 `windows` 0.58、`winreg` 0.52。
- **开发入口**: `npm run tauri dev` 会拉起 Vite `127.0.0.1:1420`。单独打开这个地址没有 Tauri，`invoke` 不可用，加载门会停在失败态。
- **打包**: `npm run tauri build` 产出安装包，安装时用静默在线引导安装 WebView2。`npm run tauri build -- --no-bundle` 只产出 exe，不安装 WebView2，不能称作单文件绿色版。

## 二、 核心业务流与规则基线

- 启动先确认 WebView2。随后并行读取待办文件、设置文件和显示器。待办与设置各自进入 `loading`、`ready` 或 `error`。空数组是成功的待办加载。缺文件或空文件用默认值。读失败或 JSON 损坏记为错误，并丢掉这份数据，避免用默认快照写回覆盖原文件。
- 只有对应领域处于 `ready` 时才允许保存。新的保存进行中时，更早一次的完成结果不能清掉更新的错误。密码锁要等设置保存成功后才上锁。
- 新增待办的草稿放在应用根上，列表卸载不会丢掉未提交文字。行内编辑草稿仍跟着那一行。
- 删除可撤销。完成一项时，若系统未要求减少动效，播放一次庆祝。减少动效时不做倾斜追随和高光扫过。
- 背景不透明度取 0 到 100。0 时淡罩和光斑几乎看不见，100 时淡罩大约盖住六成，光斑到最满。待办卡片保持实底。界面不再切换磨砂玻璃；旧设置里的 `blurMode: "blur"` 仍能读入，打开后按液态玻璃画，不为此回写磁盘。
- 贴边自动隐藏把窗口收成右侧细条，鼠标进入或点击后再展开。窗口中心不在任何显示器上时拉回主工作区并取消收起。缩放变化时若正处于收起，也取消收起。
- 开机启动读写 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\DeskSticky`。界面勾选以注册表读回值为准，空值视为关闭。设置文件写失败时回滚注册表。
- 密码锁最短 4 位。保存的是 `desk-sticky::` 加一次 SHA-256，不是加密。待办文件保持明文。内容安全策略当前为空，这是已知边界。
- 显示器枚举失败不连坐待办和设置：加载失败信息分开显示，已就绪的领域仍可保存。

## 三、 领域用语

**便利贴**:
桌面上的这一张无边框窗口，里面是待办列表。
_Avoid_: 便签应用、灵动岛

**待办**:
一条可完成、可改、可删的文本。完成与否和正文一起保存。
_Avoid_: 任务、事项卡片

**领域**:
待办或设置其中一路数据。两路加载和保存互不覆盖。
_Avoid_: 全局状态、store

**液态玻璃**:
窗口目前唯一的外观：光斑、细亮边、扫光，再加上由不透明度控制的均匀淡罩。
_Avoid_: 磨砂玻璃、亚克力开关

**淡罩**:
铺在窗口上的一层均匀半透明底，浓淡跟背景不透明度走。它不是第二张设置面板。
_Avoid_: 背景条、整卡渐变底
